โปรเจคนี้เป็นโปรเจคที่ทำขึ้นมาเพื่อให้คนที่อยากดูว่าเเม่ของผมมีผลงาน เเละผ่านประสบการณ์อะไรมาบ้าง โดยในเว็บจะมีการเเนะนำตัวของเเม่ของผมว่าจบมาจากที่ไหน เเล้วมีประสบการณ์เเละผลงานอะไรบ้าง รับทำอะไรบ้าง ช่องทางติดต่อ เเละเว็บไซต์นี้รองรับขนาดหน้าจอทั้ง Mobile Tablet Desktop โปรเจคนี้ทำให้ผมได้ฝึกการใช้ html,css,JavaScript มากขึ้น เเละได้ฝึกทักษะในการทำ responsive เพิ่มขึ้นด้วย
